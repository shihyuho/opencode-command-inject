# External Integrations

**Analysis Date:** 2026-03-30

## APIs & External Services

**OpenCode plugin host:**
- OpenCode - plugin runtime that loads this package and consumes hooks from `index.ts`, `src/plugin.ts`, and `src/plugin/command-inject.ts`
  - SDK/Client: `@opencode-ai/plugin`
  - Auth: Not handled in this repo; delegated to the host OpenCode installation

**Package publishing:**
- npm Registry - package distribution target wired in `.github/workflows/release-npm.yml`
  - SDK/Client: `npm publish`
  - Auth: GitHub Actions OIDC in `.github/workflows/release-npm.yml`; no repo-managed token file is required

**Release automation:**
- GitHub Release Please - release PR and tag automation configured in `.github/workflows/release-please.yml` and `release-please-config.json`
  - SDK/Client: `googleapis/release-please-action@v4`
  - Auth: GitHub Actions `contents: write` and `pull-requests: write` permissions

## Data Storage

**Databases:**
- Not applicable
  - Connection: None
  - Client: None

**File Storage:**
- Local filesystem only
  - Reads project `Makefile` in `src/command-sources/makefile-source.ts`
  - Reads project `package.json` in `src/command-sources/npm-scripts-source.ts` and `src/command-sources/npm-scripts-runner.ts`
  - Reads skill files `SKILL.md` under discovered roots in `src/skills/discovery.ts` and `src/skills/load-skill.ts`
  - Reads config files from `${XDG_CONFIG_HOME}/opencode/` and `.opencode/` in `src/config/loader.ts`
  - Writes generated schema artifact `opencode-command-inject.schema.json` in `scripts/generate-schema.ts`

**Caching:**
- None

## Authentication & Identity

**Auth Provider:**
- Custom / host-managed
  - Runtime plugin execution relies on OpenCode host context from `@opencode-ai/plugin` in `src/plugin.ts`
  - npm publishing identity is provided by GitHub Actions OIDC in `.github/workflows/release-npm.yml`

## Monitoring & Observability

**Error Tracking:**
- None detected

**Logs:**
- Runtime warnings use `console.warn` with stable prefixes in `src/plugin.ts`, `src/plugin/command-inject.ts`, `src/config/loader.ts`, `src/skills/discovery.ts`, and `src/command-sources/aggregator.ts`
- Use `[command-inject]` for plugin/config/discovery warnings and `[command-sources]` for source loading/collision warnings, per `AGENTS.md`

## CI/CD & Deployment

**Hosting:**
- npm package distribution; no long-running service deployment detected

**CI Pipeline:**
- GitHub Actions test pipeline in `.github/workflows/test.yml` runs Bun install, typecheck, lint, schema generation, schema drift check, and Vitest
- GitHub Actions release pipeline in `.github/workflows/release-please.yml` prepares release PRs on `main`
- GitHub Actions publish pipeline in `.github/workflows/release-npm.yml` publishes to npm on release commits or manual dispatch

## Environment Configuration

**Required env vars:**
- `OPENCODE_COMMAND_INJECT_CONFIG` - optional absolute config override path read by `src/config/loader.ts`
- `XDG_CONFIG_HOME` - optional user config root override read by `src/config/loader.ts`

**Secrets location:**
- No application secrets are stored in this repo
- GitHub Actions publish credentials are ephemeral via OIDC in `.github/workflows/release-npm.yml`

## Webhooks & Callbacks

**Incoming:**
- OpenCode hook callbacks exposed by `createCommandInjectHooks()` in `src/plugin/command-inject.ts`
  - `config` hook mutates command catalog before runtime use
  - `command.execute.before` injects rendered command text before execution
- GitHub Actions workflow triggers from `push`, `pull_request`, and `workflow_dispatch` in `.github/workflows/*.yml`

**Outgoing:**
- Reads local project artifacts and emits slash-command templates for shell execution in `src/command-sources/makefile-source.ts`, `src/command-sources/npm-scripts-source.ts`, and `src/command-sources/skill-source.ts`
- Publishes package to `https://registry.npmjs.org` from `.github/workflows/release-npm.yml`
- Publishes JSON schema artifact for editor consumption via `opencode-command-inject.schema.json`, referenced in `README.md` and generated by `scripts/generate-schema.ts`

## GitHub / CLI / Schema-Specific Notes

**GitHub integration:**
- Repository metadata, issue URL, and homepage are declared in `package.json`
- Release Please configuration is rooted at `release-please-config.json` with manifest `.release-please-manifest.json`

**CLI integration:**
- The plugin converts local `Makefile`, `package.json` scripts, and skill directories into OpenCode slash commands, as described in `README.md` and implemented in `src/command-sources/*.ts`
- npm script runner selection checks `packageManager` first, then lockfiles, in `src/command-sources/npm-scripts-runner.ts`

**Schema generation:**
- Canonical config contract lives in `src/config/schema.ts`
- Regeneration command is `bun run generate-schema` from `package.json`
- Generated output is `opencode-command-inject.schema.json`
- CI blocks stale schema artifacts in `.github/workflows/test.yml`
